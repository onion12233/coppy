# copyvideo

极简的一键 AI 视频复刻工具单页前端原型（Next.js + React + Tailwind CSS）。

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Prototype states
- Idle：上传/链接输入 + 参数选择 + 一键复刻
- Processing：阶段文案 + 进度条 + 轮询感知
- Result：视频预览 + 下载 + 再生成

设计文档：`docs/single-page-ai-video-remake-prototype.md`
